# Top Chess

A chess application with a Hono backend and mobile client.

## Project Structure

```
top-chess/
├── mobile/    # Mobile application
├── backend/   # Hono backend deployed on Cloudflare Workers
└── web/       # Web application deployed on Cloudflare Pages
```

## Getting Started

### Mobile

```bash
cd mobile
npm install
npm start
```

### Backend

```bash
cd backend
npm install
npm start
```

## Requirements

- Node.js
- npm
