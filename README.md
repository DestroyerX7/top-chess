# Top Chess

A chess application with a backend server and mobile client.

## Project Structure

```
top-chess/
├── backend/   # Node.js backend server
└── mobile/    # Mobile application
```

## Getting Started

### Backend

```bash
cd backend
npm install
npm start
```

### Mobile

```bash
cd mobile
npm install
npm start
```

## Requirements

- Node.js
- npm
