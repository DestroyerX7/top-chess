# Top Chess

A chess application with a Hono backend and mobile client.

## Project Structure

```
top-chess/
├── backend/   # Hono backend deployed on Cloudflare Workers
└── mobile/    # Mobile application
```

## Getting Started

### Backend

```bash
cd backend
npm install
npm start
```

### Mobile

```bash
cd mobile
npm install
npm start
```

## Requirements

- Node.js
- npm
