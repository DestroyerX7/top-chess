# @top-chess/db

Shared database package for **Top Chess**. It holds all of the database setup (Drizzle schema, client, and migrations) so it can be used by the [Next.js website](../../apps/web/).

## Tech Stack

- [Neon](https://neon.tech/) (serverless Postgres)
- [Drizzle ORM](https://orm.drizzle.team/)

## What's Inside

- **Schema**: table definitions for players, ratings, rankings, and rating history
- **Client**: the Drizzle client connected to Neon
- **Migrations**: generated by Drizzle Kit


### Push the Schema

```bash
cd packages/db
npm install
npx drizzle-kit push
```

Or generate and run migrations:

```bash
npx drizzle-kit generate
npx drizzle-kit migrate
```

### Browse the Data

```bash
npx drizzle-kit studio
```

## Usage

Import the client and schema from this package in the Next.js website:

```ts
import { topChessPlayers as dbTopChessPlayers } from "@top-chess/db/schema";

const topChessPlayers = await db.select().from(dbTopChessPlayers);
```
